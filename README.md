# Cash Out Closer Tool — Cloud saving

Deploy the entire extracted project through the GitHub repository linked to your existing Netlify site. Do not upload only the HTML or use a static drag-and-drop deploy. The netlify.toml sets the publish directory to public and functions directory to netlify/functions. No build command needed; Netlify installs package.json dependencies. Ensure the site's base directory is the repository root.

In Netlify: Project configuration > Environment variables. Add CASHOUT_TEAM_PASSWORD with a unique randomly generated password (at least 16 characters; 24+ recommended), available to Functions in production. Do not commit the password to GitHub. Deploy after setting it. All team members share this password; the session lasts 12 hours. Changing the password invalidates previous sessions. Open links as top-level browser tabs.

In Close create a Lead text custom field named Cash Out Analysis. In your existing Zap, add Close > Update Lead after Create Lead; map the returned Lead ID both to the Lead ID field and after the literal URL prefix https://gleaming-sorbet-27d865.netlify.app/?lead= in Cash Out Analysis. Use the dynamic ID token (not literal example text). Existing leads can be populated separately. No Close API key is needed for this tool.

Test with a dummy lead: https://gleaming-sorbet-27d865.netlify.app/?lead=lead_test123 . Log in, enter a dummy business name and earnings, save, wait for Saved status, reopen from a different browser and confirm the fields. Try a different dummy ID to check isolation. Test with dummy data before real leads. No actual deployment or live Blobs test was performed when preparing this package.

Cloud saving captures the existing full-analysis state (inputs, notes, checkbox state, selected scenario and quiz text), not webhook credentials. Saving is automatic after a brief idle period, or manual. Wait for Saved before leaving. If another team member saves first, the tool blocks overwrites; copy Full Analysis as a backup and reload before reconciling. It is not simultaneous live editing. All password holders have access to any lead ID they know. Keep access restricted to authorized staff. The base URL without a lead ID works as a password-protected standalone calculator, without cloud saving. The password is verified server-side; static HTML and JS source contain no client records. Netlify usage charges may apply.
